# **unblock.ai**
> v1.1 | Powered by OpenRouter API

A lightweight, accessible AI client designed for students needing an unblocked interface for educational and coding assistance.

If the primary domain goes down, alternative mirrors will be published using distinct subdomains (URL domain paths are case-insensitive, so capitalization does not create new URLs).

---

### **Features**
* **Dynamic Model Fallback:** Automatically switches to active free models if a provider experiences downtime.
* **Markdown Rendering:** Full support for formatted text, lists, and code blocks.
* **Zero Overhead:** Built with pure HTML, CSS, and vanilla JavaScript for fast loading speeds.

---

### **Backup Mirrors**
* `unblockai.netlify.app`
* `unblock-aicop.netlify.app`
* `unblock-aimir.netlify.app`

---

### **How to Use**
1. Enter your prompt in the text bar.
2. Press **Enter** or click the send button.
3. View the model indicator at the bottom to see which backend processed your query.
